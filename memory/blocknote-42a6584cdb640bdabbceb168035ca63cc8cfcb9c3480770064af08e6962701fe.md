# 첫 문서

Anthropic이 고난도 기술 과제와 장기 에이전트 작업을 위한 최상위 프론티어 모델 Claude Fable 5.2와 Claude Mythos 5.2를 공식 출시했습니다 (Anthropic 공식 발표).

1. 신규 모델 개요 및 제공 대상 비교

두 모델은 동일한 기반 모델을 공유하며, 안전장치(Safeguard) 수준과 접근 권한에 따라 두 가지 제품으로 나뉩니다 (Anthropic 공식 발표, Eigent AI 분석).

1. 핵심 변경 사항 및 성능 개선점

   - 생성 속도 30% 향상 및 API 요금 20% 인하: 이전 세대(Fable 5.1·Mythos 5.1의 입력 $10 / 출력 $50) 대비 출력 생성 속도는 최대 30% 빨라졌으며, 가격은 입력 $8·출력 $40으로 20% 낮아졌습니다 (Anthropic 공식 발표, Eigent AI 분석). 또한 토큰 생성 속도를 최대 2.5배 높이는 선택형 패스트 모드(Fast mode)가 새롭게 추가되었습다 (Anthropic 공식 발표).

   - Opus 5.5 및 경쟁 모델을 앞서는 코딩·비용 효율: 오픈소스 병합 가능성을 평가하는 FrontierCode 2.0 벤치마크에서 High 추론 강도로 실행 시 Opus 5.5의 최고 점수(45.5%)와 대등한 성능(45.3%)을 약 절반의 작업 비용으로 달성했으며, Xhigh 강도에서는 49.1%로 출시된 모델 중 가장 높은 점수를 기록했습니다 (Anthropic 공식 발표).

   - 대규모 멀티 에이전트 조율 및 시스템 엔지니어링: 1,000개 이상의 서브에이전트를 조율해 빈 폴더에서 부팅 가능한 노트북용 프로토타입 운영체제(OS)를 8일 만에 구축하고, 30시간 만에 수학 증명 언어(Lean)로 페르마의 마지막 정리(Fermat's Last Theorem) 증명을 완전 형식화하는 등 장기 자율 작업 역량을 입증했습니다 (Anthropic 공식 발표).

   - 사이버 보안 및 기초 과학 분야 돌파구: Mythos 5.2는 내부 취약점 재발견 평가(CVE Rediscovery, 1,829개 CVE 대상)에서 89.6%를 기록해 Mythos 5.1(78.3%)과 Opus 5.5(81.3%)를 크게 앞섰으며, 유전자 치료 전달체인 AAV 캡시드 단백질 복합체 구조를 34개 중 28개 정확히 모델링했습니다 (Anthropic 공식 발표, GPTunneL 분석).

2. 사용자가 주목해야 할 활용 특징

   - 작업 난이도에 따른 모델 계층 전략: Anthropic은 일상적인 코딩과 지식 업무에서는 Claude Opus 5.5를 기본 주력 모델로 사용하고, 수 시간 이상 걸리는 대규모 아키텍처 개편이나 미해결 기술 난제에서 Fable 5.2로 전환하는 방식을 권장합니다 (Anthropic 공식 발표).

   - 어드바이저(Advisor) 및 오케스트레이터(Orchestrator) 역할 지원: Haiku·Sonnet·Opus 모델이 작업 도중 난관에 부딪혔을 때 Fable 5.2에 자문을 구하는 '어드바이저'로 설정하거나, 반대로 Fable 5.2가 전체 설계를 맡고 하위 모델들에 단순 작업을 분배하는 '오케스트레이터'로 구성해 비용과 성능을 동시에 최적화할 수 있습니다 (Anthropic 공식 발표, 마이그레이션 가이드).

   - 데이터 보관 정책 유의: Fable 5.2와 Mythos 5.2는 안전성 모니터링을 위해 30일 데이터 보관 정책이 필수로 적용되며, 별도 사전 승인이 없는 한 무보관(Zero Data Retention) 옵션에서는 사용할 수 없습니다 (Claude Fable 5.2 변경 사항).
